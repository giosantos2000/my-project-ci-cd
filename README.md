# Projeto CI/CD com Docker

## Sobre o projeto

Este projeto acadêmico tem como objetivo praticar conceitos de Integração Contínua (CI) e Entrega Contínua (CD), utilizando GitHub Actions e Docker em uma aplicação simples desenvolvida em Java.

## Tecnologias utilizadas

- Java
- Docker
- GitHub Actions
- Git e GitHub

## Funcionalidades e recursos

- Aplicação Java executada em um container Docker.
- Pipeline de Integração Contínua (CI) configurado com GitHub Actions.
- Simulação de um processo de Entrega Contínua (CD).
- Prática de automação de etapas do desenvolvimento de software.

## Objetivos de aprendizagem

- Conhecer os conceitos de CI/CD.
- Praticar a conteinerização de aplicações com Docker.
- Automatizar etapas do fluxo de desenvolvimento utilizando GitHub Actions.
- Compreender como ferramentas de automação podem contribuir para um processo de desenvolvimento mais organizado.

## Tipo de projeto

Projeto acadêmico desenvolvido para fins de estudo e prática de ferramentas utilizadas no desenvolvimento de software.
